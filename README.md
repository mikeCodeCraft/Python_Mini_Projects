## Currency Converter

A Tkinter-based GUI app to convert between major world currencies using the CurrencyLayer API.

**Usage:**

- Enter the amount, select source and target currencies, and click "Convert".
- Requires a valid CurrencyLayer API key.

---

## QR Code Generator with Logo

Create QR codes for URLs, WiFi, Email, or WhatsApp, with options to embed a logo and customize colors.

**Usage:**

- Enter data, select QR type, optionally upload a logo, choose colors, and generate the QR code.
- Save the QR code as an image.

## Setup

1. Clone the repository:
   ```bash
   git clone <repo-url>
   cd mini_projects
   ```
2. (Optional) Create and activate a virtual environment:
   ```bash
   python -m venv venv
   # Activate the environment (Windows)
   venv\Scripts\activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
